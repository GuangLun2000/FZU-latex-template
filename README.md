### FZU-Undergrad-Thesis 英文毕业论文模版 ✅

- `FZU-thesis-latex-version-2024`
- 不仅是本科生，理论上硕士生、博士生修改后都可以直接使用。
- 格式上是依照2024年的要求，请注意您当年度的具体要求。
- 预计不会上传到overleaf，如有需要，请参考我的毕业论文项目，可以直接导入overleaf使用。本人不再负责更新和维护。
- **中文版本论文的一些参考**
- Reference 1: https://github.com/siaimes/ThesisFZU（现已停止维护）
- Reference 2: https://github.com/HuangTM23/FZU_Thesis（请注意版本适配）
